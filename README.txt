STONE ATELIER — PHOTOGRAPHIC + MOVABLE SHOWROOM

Four rooms. Five stone palettes. Three metal finishes.
Photographic mode uses Blender Cycles daylight views with matching material choices. Material regions are re-rendered with physically calculated reflections and composited over an unchanged room background. The piece zooms into the photograph.
Movable 3D loads the same furniture and room geometry with real-time lighting. Drag or use arrow keys to orbit, scroll/pinch or +/- to zoom, Home to fit the room.
Evening atmosphere and natural-oak dining bases are available in movable 3D only; the interface explicitly switches modes rather than displaying an inaccurate photograph.
Save view exports the selected photograph or 3D camera. Configuration links retain material choices for all rooms.

To run the source locally: serve dist over HTTP with any static server (for example: python3 -m http.server 8347 --directory dist).
The standalone HTML in the deliverables embeds the required assets and scripts.

All stone thicknesses remain 20 mm provisional. Room geometry is illustrative. These are visualization studies, not fabrication approvals or a guarantee of photographic indistinguishability. Exact slab selection, calibrated colour, fabrication details and structural review remain outstanding.
